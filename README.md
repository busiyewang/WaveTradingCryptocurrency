# 缠论 K 线分析工具(OKX 永续合约)使用说明

本地网页版分析工具:拉取 OKX 永续合约 K 线,按《缠论MACD币圈实战手册.html》
(同目录)自动做缠论分析与交易决策。数据只存内存,不落盘、不下单,仅供分析参考。

---

## 1. 启动与停止

```bash
# 启动(终端里完整粘贴这一行)
cd /Users/wangye/YeWang/缠论 && .venv/bin/python server.py
```

看到 `缠论K线分析工具: http://127.0.0.1:8420` 后,浏览器打开 **http://127.0.0.1:8420**。

- 停止:在启动它的终端按 `Ctrl+C`;或执行 `kill $(lsof -ti:8420 -sTCP:LISTEN)`
- 查看是否在运行:`lsof -nP -iTCP:8420 -sTCP:LISTEN`(进程名显示为 Python)
- 注意:必须用 `.venv/bin/python`(依赖装在虚拟环境里),不要用 `python3`

## 3. 基本操作

- **切币**:点 BTC/ETH/SOL/XRP/DOGE/BNB 快捷按钮;或在输入框输入任意 OKX
  合约代码(如 `PEPE-USDT-SWAP`,只输 `PEPE` 会自动补全)后点"切换"
- **切周期**:1m / 5m / 15m / 1H / 4H / 1D / 1W,每次拉取约 600 根K线
- **刷新**:点"⟳ 刷新"手动重拉;"每分钟自动刷新"默认开启,不需要可取消勾选
- **标注开关**(右上角):分型(默认关,较密)/ 笔 / 中枢 / 背驰 / 买卖点 /
  双顶底 / 收敛 / 护盘,各自独立开关
- **跳转**:面板"买卖点"栏点击任意一行,图表自动滚动到那根K线

## 5. 分析面板五栏

1. **结构状态**:最新确认笔、进行中一笔、最近中枢 ZG/ZD(是否延伸中)、
   震荡区间 GG/DD、现价位置(中枢上方/内部/下方)
2. **量价·主力**:量比=量÷MA20(>1.8放量、<0.6缩量)、量价组合含义、
   近60根位置(高/中/低位)、主力行为识别(低位吸筹/高位派发特征+证据)。
   仅基于K线量价,CVD/持仓量/链上数据未接入
3. **KDJ·RSI**:KDJ 数值与金叉/死叉/超买超卖/J值钝化;RSI 数值与超买超卖;
   RSI 背离(取最近笔端点比较):常规背离=反转(对应一类点)、
   隐藏背离=中继(对应二/三类点)
4. **背驰·形态**:背驰卡片(类型/面积比/评分条,评分含级别权重,
   "区间套"一项无法单周期自动验证恒记0,偏保守);
   双顶/双底卡片(状态、颈线、量度目标、**七项检验**逐项✓✗、缠论对应)
5. **买卖点**:历史 B/S 点列表(含评分与锁定状态),点击跳转。
   **评分 0-100,越高越可靠**,颜色分级:≥75 绿(高)/ ≥60 蓝(中)/
   ≥45 黄(一般)/ <45 灰(弱)。
   评分构成:类型基础分(手册可靠度 三类≈二类>一类)+ 结构质量
   (一类:继承背驰评分;二类:回撤浅≤38.2%加分多、回调缩量加分;
   三类:回踩离中枢边沿近、离开段突破有力、缩量回踩加分)
   × 级别权重(1m×0.55 … 4H/1D/1W×1.0,级别越大越可靠)。
   决策横幅的"信号质量"即此评分÷100。

## 6. 交易决策横幅(该不该交易)

自动综合判断,结论三种:**可考虑做多**(绿)/ **可考虑做空**(红)/ **观望**(灰)。

逻辑:上一级别定方向(看 1H 自动参考 4H,看 4H 参考 1D……)×
本级别活跃买卖点(走出新笔即过期)× 指标确认票(KDJ叉/RSI背离/量价,3票制)。
质量分 q = 方向×0.4 + 信号×0.4 + 确认×0.2 → 建议仓位(≥0.85满仓…≥0.35三成)。

硬性过滤:
- 信号与大级别方向**冲突 → 禁止操作**
- **盈亏比 <1:2 自动降级为观望**,并给出满足 1:2 的等待入场价
- 可交易时给出:入场参考、止损(结构/中枢取更保守+12根时间止损)、
  目标位、盈亏比、建议仓位

## 7. ⚡超短线模式(合约高杠杆,手册场景二)

工具栏"⚡超短线"是**开关按钮**(和背驰/买卖点开关一样用法):
- **点亮**:自动切到 5m 图,下方横幅变为三级共振结论
  (① 1H方向 → ② 5M信号 → ③ 1M扳机 → 做多/做空/观望),
  可交易时**图上直接画出价格线:蓝=入场、红=止损、绿=止盈1/2**,
  并随"每分钟自动刷新"持续更新;
- **再点一下**:关闭,恢复普通决策横幅,图上价格线消失;
- 横幅里的"仓位计算器"按钮打开计算器(自动预填入场/止损价)。

背后逻辑(一键拉取当前币种的 1H/5M/1M 三级数据):

- **① 1H 定方向**(权重40%)→ **② 5M 找二/三类买卖点**(40%,与1H冲突禁止)
  → **③ 1M 扳机**(20%:1M背驰+分型确认+突破前笔端点)
- 质量分 q≥0.85→100%仓、≥0.7→70%、≥0.5→50%、≥0.35→30%,否则观望
- 给出:止损三选一取最保守、分级止盈 40%/30%/30%(移动止盈跌破1M前笔端点离场)
- **仓位/杠杆计算器**(手册工具1):输入 权益/单笔风险%(建议0.5-1)/杠杆/入场/止损
  → 自动算 最大亏损R、开仓数量Q、保证金M、预估强平价,
  并校验硬约束"**止损距离 < 强平距离÷3**",不满足红字提示降杠杆
- 手册铁律:杠杆3-10×逐仓、同时持仓≤2、总敞口≤2%、日亏3%/周亏6%停手、
  资金费率结算与重大数据发布时段不开新仓

## 8. 买卖点确认机制(重要,必读)

**买卖点不是当前K线就能确定的,天生滞后,最新的一个在"锁定"前还会移动。**

以底部 B1 为例,最低点出现在第 T 根K线:

1. 第 T 根**收盘**后才参与计算(跳动中的K线不参与);
2. 低点之后至少 1 根处理后K线收盘,**底分型成立 → B1/背驰标记最早出现**,
   通常滞后极值 1~3 根;
3. 此时**尚未锁定**:若之后创出更低的低点并形成更低的底分型,按
   "同类型分型取更极端者"规则,笔端点会下移,**信号跟着移动(重绘)**;
4. **彻底锁定**:反向一笔成立(端点后≥5根处理后K线+合格反向分型),
   一般在极值后 5 根以上。B2/B3 同理(标在回调笔端点上)。

界面标识:

| 显示 | 含义 |
|---|---|
| 图上 `B1?` 半透明标签 | 未锁定,位置可能还会变,当"候选信号"看待 |
| 图上 `B1` 实色标签 | 已锁定,不会再变 |
| 买卖点表"状态"列 | 未锁定(黄标)/ 已锁定 |
| 背驰卡片标签 | 未锁定·或移动 / 已锁定 |
| 决策横幅信号后缀 | "未锁定·或移动"提示 |

各类信号滞后对比:

| 信号 | 滞后 | 会否重绘 |
|---|---|---|
| 历史(已锁定)买卖点 | — | 不会 |
| 最新买卖点/背驰 | 极值后 1~3 根出现 | 锁定前会 |
| KDJ叉 / RSI超买卖 / 量价组合 | 收盘即定 | 不会 |
| 超短线"1M破前笔端点"扳机 | 实时价格判断 | 不会 |

**实战用法(手册区间套)**:大级别信号刚出现(未锁定)时,不直接追,
切小级别用"背驰+分型+破前笔端点"抢确认——这正是⚡超短线模式
"1H 定信号方向、1M 定入场扳机"的设计目的;稳健做法则是等信号锁定再动手。

## 9. 分析口径说明

- 所有缠论分析只用**已收盘K线**,最后一根未收盘的只显示不参与计算,避免假信号
- MACD 为 (12,26,9),HIST=2×(DIF−DEA),与手册及国内软件一致
- 级别越大信号越可靠;背驰评分已按手册乘级别权重(1m×0.55 … 4H/1D/1W×1.0)
- "区间套"需人工验证:按手册"大级别定方向、小级别定买点"自行切周期确认

## 10. 常见问题

- **`command not found: python`** → 用完整命令
  `cd /Users/wangye/YeWang/缠论 && .venv/bin/python server.py`
- **`No module named 'requests'`** → 你用了系统 python3,改用 `.venv/bin/python`
- **`Address already in use`** → 服务已在运行,直接开浏览器;或先
  `kill $(lsof -ti:8420 -sTCP:LISTEN)` 再启动
- **加载失败/网络错误** → OKX 接口访问不通,检查网络/代理后点"⟳ 刷新"重试
- **`ls` 看不到 .venv** → 隐藏文件夹,`ls -a` 可见,属正常
