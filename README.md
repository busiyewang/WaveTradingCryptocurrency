# 缠论 K 线分析工具(OKX 永续合约)使用说明

本地网页版分析工具:拉取 OKX 永续合约 K 线,按《缠论MACD币圈实战手册.html》
(同目录)自动做缠论分析与交易决策。网页行情只存内存，不下单。
新增独立量化研究模块：历史信号回放可落库，部署目标为 MySQL，本地支持 SQLite。
完整架构与阶段计划见 [量化交易设计](docs/quant-trading-design.md)。

## 3. 基本操作

- **切币**:点 BTC/ETH/SOL/XRP/DOGE/BNB 快捷按钮;或在输入框输入任意 OKX
  合约代码(如 `PEPE-USDT-SWAP`,只输 `PEPE` 会自动补全)后点"切换"
- **切周期**:1m / 5m / 15m / 1H / 4H / 1D / 1W,每个周期拉取约 1200 根K线；多级别页大小周期各约 1200 根
- **刷新**:点"⟳ 刷新"手动重拉;"每分钟自动刷新"默认开启,不需要可取消勾选
- **标注开关**(右上角):分型(默认关,较密)/ 笔 / 线段(默认关)/ 中枢 / 背驰 / 指标背离 /
  买卖点 / 收敛,各自独立开关
- **跳转**:面板"买卖点"栏点击任意一行,图表自动滚动到那根K线

## 4. 图上标注含义

| 标注 | 含义 |
|---|---|
| 黄色折线 | 笔:端点间含端点≥5根处理后K线,两端须为整个处理后K区间的高低极值;已锁定实线,已成笔但未锁定虚线 |
| 灰色虚线折线 | 未完成的候选笔或延伸笔;尚不能构成合法笔的阻塞观察不连线 |
| 紫色粗折线 | 独立线段层,默认关闭;按特征序列判定,已锁定实线、未锁定虚线 |
| 蓝色矩形 | 笔级近似中枢连续组:ZG/ZD固定为首3笔的重叠上下沿;原子中枢最多9笔,同区间延续合并展示;未锁定边框为虚线 |
| ⚡趋势顶背驰/底背驰 | 两个严格同向且不重叠中枢的实际离开笔比较,后笔创比较区间的趋势新极值且 MACD 同向柱面积比 <0.7(数字即面积比) |
| 盘整顶背驰/底背驰 | 与同一个事先已形成中枢关联的两次同向波动,创新极值且面积比 <0.7;只作观察 |
| 上涨/下跌动能衰减 | 同向笔创新极值、面积比 <0.7,但不满足上述中枢结构;只作观察 |
| B1/B2/B3(绿) | B1 仅由结构成立的趋势底背驰生成,B2 为其后不破前低的回调,B3 为离开中枢后不回中枢的回踩;S1/S2/S3(红)对称 |
| 背离B(青)/背离S(洋红) | 指标背离信号(比缠论背驰宽松,数量更多):价创新极值而 MACD柱/DIF/RSI/KDJ/量能 拒绝确认,≥2票成立;「隐」前缀=隐藏背离(中继,须顺大级别方向用),≥3票成立;票数越多越可靠 |
| 紫色收敛虚线△ | 收敛三角形上下轨(突破后变绿↑/红↓);缠论对应=中枢震荡收敛,突破≈三类买卖点方向 |
| ▵▿(灰) | 底分型 / 顶分型 |

中枢和信号仍由当前周期的笔近似次级别走势构建,尚未实现完整递归线段中枢。
线段开关只增加独立结构图层,不会将现有中枢和买卖点切换为线段级别。
线段只用连续已锁定笔确认:先处理特征序列的包含关系,无缺口分型可确认结束,
有缺口则等待反向特征序列确认;等待中若原方向创出新极值,撤销该结束候选。
三笔用于形成初始结构,凑够三笔不等于线段已经结束;输入窗口之前的走势不作还原。

API 的 `zhongshu` 保留每个最多九笔的原子,`zhongshu_display` 为绘图和结构判断使用的连续组。
九笔上限不会使仍在同一区间震荡的走势被当作两个独立趋势中枢,也不代表已实现高级别中枢升级。
蓝框的左右端是事后回溯的结构跨度,不代表左端当时已经知道完整蓝框;初成、跨度更新和锁定时间见第9节。
分类取信号当时已形成的中枢,
不拿后来延伸或形成的最终中枢回填历史信号。低点在蓝框下方或文字标签放在蓝框下方,
都不能单独说明是哪一种背驰。

## 5. 分析面板五栏

1. **结构状态**:最新确认笔、进行中一笔、最近中枢 ZG/ZD(是否延伸中)、
   震荡区间 GG/DD、现价位置(中枢上方/内部/下方)
2. **量价·主力**:量比=量÷MA20(>1.8放量、<0.6缩量)、量价组合含义、
   近60根位置(高/中/低位)、主力行为识别(低位吸筹/高位派发特征+证据)。
   仅基于K线量价,CVD/持仓量/链上数据未接入
3. **KDJ·RSI**:KDJ 数值与金叉/死叉/超买超卖/J值钝化;RSI 数值与超买超卖;
   RSI 背离(取最近笔端点比较):常规背离=反转(对应一类点)、
   隐藏背离=中继(对应二/三类点)
4. **背驰·形态**:卡片区分趋势背驰、盘整背驰和动能衰减,展示比较两段的
   起止时间、价格、MACD 同向柱面积及面积比;评分含级别权重,
   "区间套"一项无法单周期自动验证恒记0,偏保守;
   收敛三角形卡片(状态、上下轨当前值、突破方向与缠论对应)
5. **买卖点·指标背离**:B/S 点与背离信号合并列表(含评分与锁定状态),点击跳转。
   每个买卖点附「**共振票**」:信号点±2根内的 KDJ金叉死叉 / J值钝化 /
   RSI超卖超买 / MACD柱拐头,票数越多越有把握(未锁定的最新信号右侧K线
   还没走完,票数偏少属正常,锁定后会补上)。
   背离信号的评分=五票权重和(MACD柱22/DIF16/RSI16/KDJ12/缩量12)
   +超卖超买区10 +常规背离12,×级别权重——同样越高越好。
   **评分 0-100,越高越可靠**,颜色分级:≥75 绿(高)/ ≥60 蓝(中)/
   ≥45 黄(一般)/ <45 灰(弱)。
   评分构成:类型基础分(手册可靠度 三类≈二类>一类)+ 结构质量
   (一类:继承背驰评分;二类:回撤浅≤38.2%加分多、回调缩量加分;
   三类:回踩离中枢边沿近、离开段突破有力、缩量回踩加分)
   × 级别权重(1m×0.55 … 4H/1D/1W×1.0,级别越大越可靠)。
   决策横幅的"信号质量"即此评分÷100。

## 6. 交易决策横幅(该不该交易)

自动综合判断,结论三种:**可考虑做多**(绿)/ **可考虑做空**(红)/ **观望**(灰)。

逻辑:上一级别定方向(看 1H 自动参考 4H,看 4H 参考 1D……)×
本级别活跃买卖点 × 指标确认票(KDJ叉/RSI背离/量价/
信号点共振≥2票,4票制)。
质量分 q = 方向×0.4 + 信号×0.4 + 确认×0.2 → 建议仓位(≥0.85满仓…≥0.35三成)。
活跃范围覆盖最新锁定笔端点起及较新的候选;暂无锁定笔时看最近两条成笔。
等有更新的笔锁定,旧信号才移出范围,不以仅多出一笔就提前淘汰仍在等待锁定的信号。
单周期、多级别与量化共享这一范围;量化仍只选择最新 B2/B3/S2/S3 且要求已锁定,
价格失效、方向和扣费后盈亏比等条件继续独立过滤。

硬性过滤:
- 信号与大级别方向**冲突 → 禁止操作**
- **盈亏比 <1:2 自动降级为观望**,并给出满足 1:2 的等待入场价
- 可交易时给出:入场参考、止损(结构/中枢取更保守+12根时间止损)、
  目标位、盈亏比、建议仓位

## 7. 多级别联动页(先大后小,区间套)

顶部工具栏「🔭 多级别」进入(或直接开 http://127.0.0.1:8420/multi)。
核心心法:**大级别定方向、找关键位;小级别只在关键位上找确认**。

- 左图=大级别(默认 4H):定方向(中枢位置+笔方向)、给关键位;
  右图=小级别(默认 15m):找确认信号。**两图都画出大级别关键位横线**:
  绿=下方支撑、红=上方压力、灰=EMA 辅助;加粗+「◀测试中」=现价正在测试
- 关键位口径:结构位优先(中枢 ZG/ZD、前高/前低笔端点),EMA20/40 仅辅助;
  「测试中」容差 = 0.6 × 大级别近20根平均振幅(自适应,横幅中有显示)
- 小级别可用信号只有落在某个大级别关键位±容差内才算位置验证;
  远离关键位的标为杂波。**盘整背驰和动能衰减即使靠近关键位,也只作观察,
  不能独立作为入场确认**。两张图均明确显示背驰类别。
  **千万不要用"小级别涨了"去推导"大级别要涨"**
- 决策横幅口径与单级别一致:信号与大级别方向冲突→禁止操作;
  盈亏比<1:2→观望并给等待入场价;综合评分 0-100 越高越好。
  目标位**结构位优先**(均线会移动,不拿它当目标);几乎重合的关键位
  (相距<四分之一容差)自动合并显示(如「中枢下沿 ZD ≈ EMA20」)
- **场景三 · 放量突破关键位 = 观察信号**:小级别放量K线(≥2×前5根均量)
  收盘穿越某个大级别关键位时,横幅会提示——但明确标注"非入场依据,
  等大级别收盘确认",防止用一根小级别K线去推大级别方向
- 第三栏「刹车印 · 持仓检查」回答"一直涨(跌)什么时候算结束",
  **视角跟随大级别方向**(4H 涨就按持多仓检查,小级别回调不会误切成空头视角):
  ① 反向背离/背驰 = 预警(逼空行情背了又背常见,不是离场理由);
  ② 放量滞涨/滞跌 = 量≥前5根均量×3 且小实体/长影线;
  ③ 收盘**连续**跌破(站上)小级别 EMA20 —— 只有③才算确认。
  组合结论:情况A 持有不动 / 情况B 减30-40%浮动仓 / 情况C 清浮动仓
- 级别搭配推荐 1D→1H、4H→15m、1H→5m、15m→1m,选了不合法组合会自动纠正;
  币种与单级别页共享,来回切换不用重选

## 8. 仓位 / 杠杆计算器(手册工具1)

决策横幅右侧「仓位计算器」按钮打开(自动按当前决策预填方向/入场价/止损价,
观望时可自行手填):输入 权益 / 单笔风险%(建议 0.5-1)/ 杠杆 / 入场 / 止损
→ 自动算 最大亏损 R、开仓数量 Q、保证金 M、预估强平价,
并校验手册硬约束「**止损距离 < 强平距离÷3**」,不满足红字提示降杠杆或收紧止损。

手册铁律:杠杆 3-10× 逐仓、同时持仓 ≤2、总敞口 ≤2%、日亏 3%/周亏 6% 停手、
资金费率结算与重大数据发布时段不开新仓。

## 9. 买卖点确认机制(重要,必读)

**笔、线段、中枢与买卖点都有确认过程,未锁定结构可能移动或撤回。**

以满足趋势背驰结构的底部 B1 为例,最低点出现在第 T 根K线:

1. 第 T 根**收盘**后才参与计算(跳动中的K线不参与);
2. 等右侧处理后K线使底分型成立,并满足成笔、趋势结构和力度条件,才可能出现
   **B1/趋势底背驰候选**。包含关系会改变等待长度,没有固定几根原始K线的保证;
3. 未锁定尾部保留所有已知分型,包括曾因距离不足而未入选者,重新选择通向最新可达分型的
   最长合法交替路径。后续新极值可能使尾部回退重选,**笔和信号随之移动或撤回**;
4. 当前算法中,候选端点之后至少已有两笔确认笔,且该端点仍是待调整尾部的同类型极值,
   才可能锁定。依赖它的中枢和信号还需满足各自证据的锁定条件,不承诺固定根数。

B3/S3 使用离开笔之前已经形成的中枢快照,检查实际离开笔与紧接的回踩/回抽笔。
向上离开后回踩终点必须严格高于 ZG,向下离开后回抽终点必须严格低于 ZD;
触边或重新进入区间不成立。离开笔即使被计入中枢跨度,也不会再被错认成下一笔。

`known_at` 是结构首次可知事件K线的收盘时间;中枢 `span_known_at` 是当前完整跨度可知的收盘时间;
`locked_at` 是证据满足锁定条件的收盘时间。对应 `*_idx` 是当前输入内的K线索引。
图上端点、蓝框起止及信号极值仍落在历史极值位置,这些位置不能当成可入场时间。
线段确认使用证据笔的锁定事件,通常晚于普通分型或笔的首次成立。

界面标识:

| 显示 | 含义 |
|---|---|
| 图上 `B1?` 半透明标签 | 未锁定,位置可能还会变,当"候选信号"看待 |
| 图上 `B1` 实色标签 | 在同一历史起点下已锁定;不等于滚动窗口永不重算 |
| 买卖点表"状态"列 | 未锁定(黄标)/ 已锁定 |
| 背驰卡片标签 | 未锁定·或移动 / 已锁定 |
| 决策横幅信号后缀 | "未锁定·或移动"提示 |

各类信号滞后对比:

| 信号 | 滞后 | 会否重绘 |
|---|---|---|
| 历史(已锁定)结构与买卖点 | 以实际 locked_at 为准 | 固定历史起点追加时保持锁定;窗口左端变化会重算 |
| 未锁定买卖点/背驰 | 分型、合法笔与结构证据齐备后出现 | 可能移动或撤回 |
| KDJ叉 / RSI超买卖 / 量价组合 | 当前输入上收盘后计算 | 窗口变化仍可能影响指标初值 |

网页只保留约1200根K线,刷新后窗口左端会向前移动。包含方向、初始笔和线段的起点可能随之重算;
不能将固定历史起点下的追加稳定性,解释成不同滚动窗口之间的所有历史标注都不变。

**实战用法(手册区间套)**:大级别信号刚出现(未锁定)时,不直接追,
切小级别(如 4H 信号切到 15m/5m)用「背驰+分型+破前笔端点」抢确认;
稳健做法则是等信号锁定再动手。

## 10. 分析口径说明

- 所有缠论分析只用**已收盘K线**,最后一根未收盘的只显示不参与计算,避免假信号
- MACD 统一为 (10,20,5),DIF=EMA10−EMA20,DEA=EMA5(DIF),HIST=2×(DIF−DEA),与手册一致
- 级别越大信号越可靠;背驰评分已按手册乘级别权重(1m×0.55 … 4H/1D/1W×1.0)
- "区间套"需人工验证:按手册"大级别定方向、小级别定买点"自行切周期确认

## 11. 常见问题

- **`command not found: python`** → 用完整命令
  `cd /Users/wangye/YeWang/加密货币/缠论 && .venv/bin/python server.py`
- **`No module named 'requests'`** → 你用了系统 python3,改用 `.venv/bin/python`
- **`Address already in use`** → 服务已在运行,直接开浏览器;或先
  `kill $(lsof -ti:8420 -sTCP:LISTEN)` 再启动
- **加载失败/网络错误** → OKX 接口访问不通,检查网络/代理后点"⟳ 刷新"重试
- **`ls` 看不到 .venv** → 隐藏文件夹,`ls -a` 可见,属正常

### 配置 MySQL

准备独立 MySQL 8.0.16+ 数据库（建议在 MySQL 8.4 验证），安装可选驱动：

```bash
.venv/bin/python -m pip install -r requirements-quant.txt
```

在本地环境设置 `DATABASE_URL=mysql://用户:密码@主机:3306/数据库` 后运行 `init-db`。
用户名/密码中的特殊字符需 URL 编码；不要把真实密码写入文档、聊天或 Git。
远程 TLS 可追加 `?ssl_ca=/absolute/path/ca.pem`。模板见 `.env.example`；
程序**不自动加载 .env**，需由终端环境或后续服务管理器注入。
无需创建欧易 API Key。

连接专用测试库后，可另设置 `QUANT_TEST_DATABASE_URL` 再运行测试；
MySQL 测试会建研究表并留下测试运行记录，不删除现有数据。未设置时该测试明确跳过。

### 输入真实历史数据

准备一个 JSON 对象，包含 `inst`、`4H`、`15m` 三个字段。
周期字段是升序、连续 K 线数组，每根形如：

```json
{"ts": 0, "o": 2000, "h": 2010, "l": 1990, "c": 2005, "vol": 100, "confirm": 1}
```

`ts` 是 UTC 毫秒开盘时间，必须按周期对齐；上述时间仅演示格式。
品种只支持 `BTC-USDT-SWAP` / `ETH-USDT-SWAP`。至少 40 根 4H 和 80 根 15m，
且预热后时间范围重叠，大级别历史须覆盖小级别评估区间。
输入可带一根 `confirm: 0` 的末尾 K，回放会排除；重复、缺口、乱序、非法 OHLCV 会报错。
数据下载器尚未实现，不能将页面的 1200 根小周期数据直接视为完整回测数据集。

```bash
.venv/bin/python -m quant replay var/history.json --fee-rate 0.0005 --slippage-rate 0.0005
.venv/bin/python -m quant report YOUR_RUN_ID
```

两项费率是单边比例研究假设，须替换为实际情况；当前尚未计历史资金费。
相同信号只输出一次研究候选，回放任务之间独立。信号快照记录的是“当时看到什么”，
不是把最终历史买点回填到过去；首次评估时已有的信号带 `first_observation_left_censored` 标记。

### 研究模块常见问题

- `python` 不存在：使用上述 `.venv/bin/python`，不要用系统解释器替代。
- 提示 MySQL 驱动缺失：安装 `requirements-quant.txt`；SQLite 不需要该驱动。
- 迁移校验和不一致：不要编辑已应用迁移；新改动新增版本。不要删除有价值的研究库绕过检查。
- 程序异常：检查运行记录是否为 failed。进程被强制终止可能留下 running，重新回放生成新任务。
- 修改量化模块后直接重跑命令；它独立于 Flask，此模块开发无需重启或占用 8420。
- 现有网页服务修改 Python 后仍需重启；本机访问 localhost 仍须避开代理。
